# Portfolio 4 – NoSQL and Advanced Data Models

MongoDB is used as a complementary property-catalogue/read model. The MySQL database remains authoritative for reservations, room allocation, payments and refunds.

## Run
1. Start MongoDB or create a MongoDB Atlas database.
2. Open `mongosh`.
3. Run `mongodb/01_setup_and_seed.js`.
4. Run `mongodb/02_queries_and_aggregation.js`.
5. Capture collection/document/query/index evidence.

Do not copy production personal data or credentials into the sample dataset.
